# Project instructions

This is a personal, single-workspace job prototype. Preserve the separate ownership of employer listing facts, owner review decisions, application tracking and AI advice.

Use fictional fixtures for tests. Never operate on the owner's application database during automated tests. Keep configuration profiles, databases, keys, screenshots and migration archives out of Git. Do not enable paid provider calls merely to run tests. Keep browser tests sequential because they share QA port 18084.

Read docs/COMPLETE-GUIDE.md for the implemented behavior and known limits. Treat macOS, hosted CI and paid provider execution as unverified until observed on those targets. No native client is included.
