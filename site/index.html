Your search preferences

These settings control your personal search and explainable matching rules. Saved records and application history are retained.

Employer boards

Use the employer slug from its board URL. For jobs.ashbyhq.com/deepgram, enter deepgram. Additions take effect on the next search.

Schedule and AI

AI is optional and runs per job when you click Request AI review. Your profile and posting are sent; application notes are excluded. Keep the API key on the server in secrets/openai.key. The request limit bounds attempts, not dollars. Firecrawl remains disabled.

From employer posting to your next step

1. Discover

The Python backend reads employer feeds and checks posting URLs. It stores listing facts in SQLite and reports source failures.

2. Understand

Your title and skill rules rank the jobs. Optional AI compares your experience with a posting and suggests questions. Missing evidence stays uncertain.

3. Decide and track

You review location, salary and the application. Approval prepares the job for you to apply on the employer site. Notes and progress are saved separately.

Project map: index.html is the structure, the two JavaScript files handle interaction, app.py handles HTTP and discovery, prototype.py handles preferences, source health and AI. data/jobs.sqlite3 stores records. Docker connects those pieces.

For your Mac: this web prototype can continue running on the Windows host while you access it through your private network. The versioned JSON API is the starting point for a future SwiftUI client. Xcode is a separate client project; this release does not claim to include an iOS app.

Application tracking is saved in the shared database. Search never submits applications or changes your tracking. Imported history needs confirmation. Missing salaries and uncertain eligibility stay in review.
